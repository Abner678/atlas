一个纯静态、无构建依赖的研究型交互页：把 16 种赚钱逻辑做成一张可拖拽的物理星图，把每一种逻辑拆成可调参数的商业闭环，再把闭环变成可用虚拟资金投资的「模式资产」。

## 新增：认知区（knowledge.html）

100 条认知模型，按 5 类归档（认知与心理 28 / 经济与博弈 20 / 效率与执行 16 / 人际与影响 16 / 组织与战略 20）。

**这一页最有价值的地方不是收录，是分级。** 原图把 100 条并称「世界顶级认知」，但它们混了三种成色：

| 等级 | 含义 | 占比 |
|---|---|---|
| **学术** | 有提出者与实证研究 | 67 |
| **经验** | 行业共识，无严格证明 | 15 |
| **俗语** | 中文商界流传的管理隐喻（木桶定律、鲇鱼效应、猴子理论…） | 18 |

每条卡片都带「怎么用」和「引用注意」——点开俗语类条目，会明确告诉你**它没有对应的学术研究，可以当比喻，不适合当结论引用**。

其他功能：分类筛选、全文搜索（名称/释义/用法）、右侧详情抽屉、移动端单列。

数据源：`assets/knowledge.js` 由 `第一项目/知识区/knowledge.json` 生成（`node _genknowledge.js`）。
原图第 77 与第 87 条重复（即时反馈效应），去重后 99 条 + 1 条重复标注 = 100。

### 三个视角：按逻辑 / 按需求 / 按人性

树的第一层可以切换。**16 种逻辑回答「怎么赚」，需求体系回答「为什么有人愿意付」。**

| 视角 | 第一层 | 根节点 |
|---|---|---|
| **按逻辑** | 勤快 / 增值 / 差异 / 借力 | 16 种赚钱逻辑 |
| **按需求** | 生存 / 安全 / 归属 / 尊重 / 自主 / 意义 | 人为什么愿意付钱 |
| **按人性** | 贪婪 / 懒惰 / 傲慢 / 嫉妒 / 色欲 / 暴食 / 暴怒 / 恐惧 / 爱 / 成就 | 钱是从哪股人性里出来的 |

**同一条路径会出现在多个需求下**——这不是重复，是它本来就同时满足好几层需求。
比如「赚地域差」既在**生存**（便宜），也在**归属**（老家的味道）。

#### 分布上看出来的东西

| 需求层 | 命中路径 |
|---|---|
| 安全 | **6 条**（最拥挤的一层：人怕出错胜过想占便宜） |
| 尊重 | 6 条 |
| 归属 | 4 条 |
| 生存 / 自主 | 各 3 条 |
| 意义 | 1 条（赚执行差） |

| 人性驱动 | 命中路径 |
|---|---|
| **贪婪** | **6 条**（最大的一股） |
| 恐惧 | 4 条 |
| 懒惰 / 傲慢 | 各 3 条 |
| 暴食 / 爱 | 各 2 条 |
| 嫉妒 / 色欲 / 暴怒 / 成就 | 各 1 条 |

> **贪婪最大，恐惧第二。** 这解释了为什么「省钱」和「怕错过」的生意最好做，也解释了为什么"教育用户"的生意最难做——它既不省钱也不制造恐惧。

#### 每条路径都写了「为什么愿意付」

点开任意路径，面板第一块就是：

```
为什么有人愿意付
需求层   [生存]
人性驱动 [贪婪]
「人不是想买便宜货，是想占便宜。同一件东西，
 知道自己比隔壁买得便宜，那一刻的得意本身就是商品。
 所以差价生意卖的从来不是价格，是「我买对了」的感觉。」
```

#### 一句诚实的说明

**七宗罪不是心理学理论**，是营销语境里好用的直觉分层——它解释「情绪怎么被定价」，不解释「人为什么活着」。
所以驱动层里同时保留了**恐惧（最强）、爱（正向）、成就（正向）**，否则整张表会很犬儒。

需求层也一样：同一件事可以被不同需求解释（买便宜货既可能是真缺钱，也可能是不缺钱但想占便宜），归类取主要那一层，次要的写在 why 里。

## 新增：超级树（tree.html）

一张可缩放的树，把 16 种赚钱逻辑的所有维度摊开：

```
16 种赚钱逻辑（根）
├─ 勤快 / 增值 / 差异 / 借力            ← 4 大类
│  └─ 01 赚差价的钱 … 16 赚执行差的钱   ← 16 条路径
│     ├─ 做法       5 条
│     ├─ 闭环       6 步
│     ├─ 职业人群   5 类
│     ├─ 优势地域   4 处
│     ├─ 国家文件   8 件   ← 带 gov.cn / npc.gov.cn 原文链接
│     ├─ 风险       5 条
│     └─ 可连接     4 条   ← 虚线连到别的路径
```

**规模**：默认 21 个节点；全展开 **714 个节点**（4 大类 + 16 路径 + 112 组 + 581 条目），**64 条跨枝连线**，42 件去重后的国家文件。

### 为什么是渐进展开

714 个节点一次铺开，在 1440px 上要缩到 **8%**，变成一根细条——没人看得清。
所以默认只到「路径」这一层，点哪条路径就展开它的 7 个组，再点组才出条目。
**每一次展开都是看你想看的那一枝，不是看整棵树的缩略图。**

### 交互

| 操作 | 效果 |
|---|---|
| 点路径卡片 | 右侧（手机：底部）弹出详情：资金 / 周期 / 毛利 / 难度 / 利润公式 / 核心逻辑 / 做法 / 闭环 / 职业 / 地域 / 国家文件 / 风险 / 指标 / 第一周 / 可连接 |
| 点 `+` | 展开或收起这一枝的组 |
| 点「可连接」里的条目 | 跳到那条路径，树的另一处亮起来 |
| 拖动 / 滚轮 / 双指 | 平移 / 缩放 |
| 顶部大类标签 | 只看「勤快 / 增值 / 差异 / 借力」其中一类 |
| 搜索 | 按路径名、做法、职业、核心逻辑匹配，命中的亮、其余变暗 |
| 连接线 | 可开关；选中某条路径时，它的连接线加粗高亮 |
| 重置 | 回到「4 大类 + 16 路径」 |

### 国家文件是一手依据

每条路径都挂 4–8 件国家文件，条目上直接显示**效力等级**和**发文机关**，点 ↗ 打开原文：

- 法律：电子商务法、消费者权益保护法实施条例、食品安全法
- 行政法规：促进个体工商户发展条例、互联网平台企业涉税信息报送规定
- 部门规章：网络交易监督管理办法、网络反不正当竞争暂行规定
- 国务院文件：关于加快构建废弃物循环利用体系的意见

**政策是这套树里唯一「不可争辩」的部分**——别人的经验可以质疑，条文不行。

### 窄屏

390px 下：列宽压到 52%、隐藏副标题、按高度装（保证字能读），宽度不够就横向拖。
移动端默认 100% 而不是缩到 38%。

### 技术

- `assets/supertree.js`：整齐树布局（叶子排队、父取子均值）+ 渐进展开 + 语义缩放
- 主干用实线贝塞尔，跨枝连接用虚线，路径颜色继承大类
- 无依赖、无构建，直接双击 `tree.html` 即可

## 这一版新增了什么


### 1. PTC 模式（Physics Tree Canvas / 物理体系图）

入口：全景树区块顶部的黑色卡片「PTC 模式」。

- 4 条主干 → 16 条路径 → 88 个做法，Canvas 2D 绘制，带锚点、弹簧、斥力与回弹。
- 拖动节点会改变它的锚点，松手后留在新位置；「重置」恢复原始结构。
- 滚轮 / 双指缩放，拖动空白平移，点节点打开右侧详情。
- 点路径后可以展开它的做法，或者直接跳回原来的完整闭环抽屉。
- 支持搜索、按主干筛选，路径之间的「可以连接」会以流动虚线显示。
- 移动端使用简化标注：只显示主干名与路径点，点开看详情。

### 2. 闭环工坊（Loop Forge）

入口：导航「工坊」、Hero 的「造一个闭环」，或任意路径详情里的「为这条路径造一个闭环」。

同一条路径可以长出四种商业闭环：

| 模型 | 收费结构 | 关键风险 |
| --- | --- | --- |
| 一次性买断 | 卖一件，收一次 | 现金流快，复购弱 |
| 免费 + 服务费 | 先送设备，按月收 | 回本周期是生死线 |
| 订阅 / 会员 | 按月持续交付 | 留存比拉新更值钱 |
| 平台抽佣 | 按成交抽佣 | 冷启动与双边信任 |

可以做：

- 拖动 6 个参数（售价、成本、月费、获客、流失、增速等），实时重算单位经济与 12 个月现金流。
- 看 6 步闭环图、单客毛利、LTV、回本周期、LTV/CAC、12 个月利润与累计现金曲线。
- 用「对比两种闭环」直接比较同一路径的两种收费结构（默认是手机：卖一台 vs 0 元送机 + 月费）。
- 保存成一张「模式资产」，进入模式市场。

### 3. 模式市场（Mode Market）

- 初始 100,000 虚拟币；可买入 / 卖出模式资产，价格由页面内的模型与模拟情绪生成。
- 模式价格不是股价：评分主要看 LTV/CAC、回本周期、12 个月现金流与复制能力。
- 每 6 秒模拟一次行情；持仓、现金、关注列表都存本地。
- 「用这个闭环」可以把市场上的模式参数载回工坊继续改。
- 明确是模拟盘：不接真实资金、不构成投资建议。

## 数据与参数

- `assets/lab-data.js` 里的 `archetypes` 是四种闭环原型的文案与公式；`methods` 是 16 条路径的基准经济（客单价、成本、获客、流失、月新增等）。
- 调整某个路径的默认值，改 `methods.M01` 这类对象即可。
- 市场种子资产在 `seeds`；想清空用户资产，浏览器控制台执行 `localStorage.removeItem("atlas.market.v1")`。

## 本地存储

| key | 内容 |
| --- | --- |
| `atlas.market.v1` | 虚拟现金、持仓、关注、用户发布的模式、模拟价格与历史 |

原有页面还会使用 `atlas.loop.v1` 保存 90 天闭环勾选进度。PTC 与工坊参数不持久化。

## 边界

- **这是前端原型**：所有「发布 / 投资 / 持仓」都只发生在当前浏览器，没有账号、后端、多人共享或真实结算。
- 页面中的金额、毛利、周期、模式价格均为假设或模拟，不承诺收益。
- 如果要变成真的「投资商业模式」的产品，涉及证券 / 众筹 / 支付 / 投资者适当性等合规问题，需要另做法律与牌照评估，不能直接把这套模拟盘上线收钱。
- 政策部分以国家文件原文为准；本页不构成法律、税务、投资或经营建议。
